A photo's caption comes from its `resources` front-matter entry: `title` for a short line, `params.description` for longer text under it, either optional and both markdown. They show in the lightbox only — the grid is for scanning. Hugo defaults a resource's `.Title` to its `.Name`, so a title counts only when the two differ — an untitled photo gets no filename caption. The alt text is the title, then the description, then the album's. The caption is a `template data-caption` _after_ the tile, never inside it. A markdown link in a caption is an `a`, and inside the tile's own `a` the parser would close the tile at the inner start tag. A `template` is `display: none`, so it is no flex item and adds no gap; `baseof.html`'s `captionContent` reads it from the tile's next sibling. AutoOrient runs first: phone photos store rotation as an EXIF tag, and Hugo's resize ops ignore it, so a portrait shot would otherwise come out sideways, and its aspect ratio below would be the wrong way round. The grid is a justified layout, Google Photos' shape: every photo in a row is the same height, each keeps its own aspect ratio, and the row fills the column. It is pure flexbox. Each tile's `flex-grow` and `flex-basis` are both proportional to its aspect ratio `--ar`, so the space a row grows by is shared out in that ratio, and `aspect-ratio` turns every tile's width back into one common height. The basis is the target row height times `--ar` — 8rem on a phone, 12rem from `sm` — and rows end up somewhat taller than that, since they grow to fill. `--ar` is an inline `style`, not an arbitrary-property class: the value differs per photo and is computed at build time, so a `[--ar:1.333]` class would exist as a literal nowhere and miss the build that renders it. The trailing spacer is what keeps the last row from stretching: it grows 999 times harder than any tile, so it takes a short row's slack and leaves those photos at the target height. It has zero basis, so it fits onto whichever line the last photo is on and never starts a row of its own. */}} {{ $photos := sort (.Resources.ByType "image") "Name" }} {{ with $photos }}
