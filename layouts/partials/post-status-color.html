{{/* Usage: `partial "post-status-color.html" .` — the single place a blog post's status colour is decided. Returns a dict holding `chip`, a literal class string for the flat badge, so it needs no safelist. (A dict rather than the string because a second shape, the post card's gradient `ramp`, sat beside it until the card was removed in 4.15.0.) The colours are the `--status-*` variables in main.css — one warm ramp, identical in both themes. An unknown or archived status falls through to the paper chip, the one entry that *is* theme-aware. `return`, not rendered output, and that is load-bearing: a partial that ends by printing hands its caller the template's text, newlines and all. This one used to, returning "\n\nprimary" and silently uncolouring every status on the site. */}} {{ $archived := dict "chip" "badge-ghost" }} {{ $status := dict "seed" (dict "chip" "[--badge-color:var(--status-seed-deep)] [--badge-fg:var(--status-seed-ink)]") "growing" (dict "chip" "[--badge-color:var(--status-growing-deep)] [--badge-fg:var(--status-growing-ink)]") "living" (dict "chip" "[--badge-color:var(--status-living-deep)] [--badge-fg:var(--status-living-ink)]") "archived" $archived }} {{ return (index $status (.Params.status | default "") | default $archived) }}
