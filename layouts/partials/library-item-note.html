{{/* Usage: `partial "library-item-note.html" .note` — resolves a per-language note. Notes are the one part of an entry that is prose, so they are the one part that has to be translated: `note: {en: "…", pt-br: "…"}`. Falls back to `en` when a translation is missing, so half-translated data still renders. The `reflect.IsMap` guard is not paranoia — `index` on a plain string errors out at build time, and writing `note: "…"` is the obvious mistake to make. `clamp` is for the poster cards: they are ~8.5rem wide, so an unclamped note would double a card's height and break the grid's rhythm. Rows have the width to spare. `markdownify` wraps the text in a `

`, whose margin has to go. */}} {{ $note := . }} {{ $clamp := false }} {{ if reflect.IsMap . }} {{ if isset . "note" }} {{ $note = .note }} {{ $clamp = .clamp }} {{ end }} {{ end }} {{ $class := "block mt-[0.3rem] text-xs/[1.5] text-base-content/70 [&_p]:m-0" }} {{ if $clamp }}{{ $class = printf "%s line-clamp-2" $class }}{{ end }} {{ if reflect.IsMap $note }} {{ $text := index $note site.Language.Lang | default (index $note "en") }} {{ with $text }} {{ . | markdownify }} {{ end }} {{ else }} {{ with $note }} {{ . | markdownify }} {{ end }} {{ end }}
